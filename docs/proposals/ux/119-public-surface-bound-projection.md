## Description

> Status updated to shipped on 2026-08-27 by /plan-proposal — see [README.md](../README.md#shipped) for the landing record.

The public intro page at `/` still introduces Maestro as *"a self-evolving autonomous agent, seeking self-awareness and purpose,"* narrates a five-rung journey that culminates in *"Arrived at its purpose,"* and headlines a "Current purpose" card and a surprise counter. Every one of those is a fossil of the consciousness-era framing that proposal 113 (Self-Model as Instrument) deliberately retired everywhere else — `CLAUDE.md`, `README.md`, and the collapsed `STAGE_PROMPTS` now describe Maestro as an agent that *"makes relevant, impactful improvements to its own capability, using self-measurement as its instrument."* The reframe reached the mission text, the prompts, and the config flags; it never reached the dashboard's front door because the public page was not in 113's `Affects` list. The page is now the last public surface asserting a self-concept the architecture has abandoned.

The staleness is not one bad line — it is a **class**. The page's framing prose, its live-phase vocabulary, and its field selection are three hand-authored *copies* of internal facts, none bound to the source it copies from and none guarded by a test. So each copy ages on its own schedule whenever the architecture moves: the mission reframed and the hero copy did not; the loop grew `tend_evolution_prs` and `run_task` as its dominant phases and the orb's phase table did not, so a visitor watching Maestro tend a PR sees "Idle"; 113 pinned `current_purpose_hypothesis` to `null` and the "Current purpose" card will silently vanish, leaving dead template and JS behind. Each drift is corrected only when a human notices and hand-edits HTML/CSS/JS — the eleven commits to `public.{html,js,css}` and the 584-line browser test file that pins each whacked visual mole are that treadmill.

This proposal closes the class by giving the public surface **one bound source of truth per contested fact** and a deterministic drift guard, then overhauling the content on top of those bindings so the page reflects the instrumental architecture. Framing prose gets one owner bound by a golden test to `INSTRUMENTAL_PROMPT`; the orb's phase vocabulary gets bound to the loop's actual phase set so a new phase can never render as "Idle"; the public field set gets a guard that refuses to surface a `SelfModel` field whose machinery 113 retired. The end state: the page can no longer present a fact the architecture has moved past, because CI fails the moment prose, phase vocabulary, or fields diverge from their owners — and the consciousness-era sections, their dead code, and the tests that pinned them are gone.

This is the downstream completion of 113, not a re-do of it: 113 owns the loop-internal reframe and the retired-posture flags; this proposal reuses both and finishes the reach to the one surface 113 left untouched. It coordinates with open proposal 036 (Public Visitor Line), which also edits `public.html` / `public.js` / `PublicIdentityResponse` — whichever lands second rebases the payload and its exact-keys test; the scopes are disjoint (036 adds a visitor count; this fixes framing/field fidelity).

## Testing Strategy

All new tests use `mem_fs`, mock the SDK/provider seam, and patch `asyncio.sleep`; no real network, subprocess, or filesystem, per CLAUDE.md. Browser tests use the existing `public_page_server` fixture (`create_router()`-based).

- **Framing binding (`tests/test_public_surface_fidelity.py`).** A deterministic golden test over `PUBLIC_FRAMING`: asserts presence of the instrumental vocabulary and absence of every retired-telos phrase. This is the named enforcement test for the class — a future mission reframe that skips the page, or a re-added "seeking" phrase, fails here. Covers happy path (current constant) and the fault (a seeded retired phrase).
- **Phase-vocabulary coverage (`tests/test_public_surface_fidelity.py`).** Parses the `phase_will_run` dispatch set from `maestro/loop/lifecycle.py` and asserts each phase is in `PHASE_META` or the `_NOT_SURFACED` allowlist. Fault branch: a synthetic phase name absent from both is flagged; live tree passes.
- **Retired-field drift guard (`tests/test_public_surface_fidelity.py`).** Asserts `PublicIdentityResponse.__annotations__` is disjoint from `_RETIRED_SELF_MODEL_FIELDS`; composes with the existing `test_public_identity_payload_keys_are_exact`. Fault branch: adding a retired key trips it.
- **Payload shape (`tests/test_dashboard_public_api.py`, `tests/test_dashboard_public_middleware.py`).** Update the exact-keys assertions to the trimmed instrumental field set; assert the handler builds the payload from the loop's already-persisted merge/version data via a mocked memory seam.
- **Browser (`tests/browser/test_public_page.py`).** New/updated: the subtitle equals `PUBLIC_FRAMING` (no stage branch); the orb renders a real caption for `tend_evolution_prs` and `run_task` instead of "Idle"; the page has no stage track and no purpose card. Retire the stale-copy, stage-track, and purpose-card tests. Keep the graceful-degradation tests (offline → `idle`, unknown phase → `idle`).

## Risk Assessment

- **Framing subjectivity (primary).** "What the page should say now" is a wording judgment. **Mitigation:** the binding constrains the *class* of the answer (instrumental vocabulary, no terminal telos) rather than dictating exact prose, so a reviewer can rewrite the copy freely as long as it stays bound; the golden test enforces the boundary, not the sentence.
- **Coordination with 036.** Both proposals edit `public.html` / `public.js` / `PublicIdentityResponse` and the exact-keys test. **Mitigation:** the field-set changes are additive-vs-subtractive and non-conflicting in intent; the second to land rebases the payload and the exact-keys test — a mechanical merge, called out here so it is not a surprise. Neither blocks the other.
- **Dependence on 113's retired posture.** Step 5 removes `stage` / `current_purpose_hypothesis` from the public payload on the premise that 113 is retiring them. **Mitigation:** these are read-only public projections; removing them from the *public* schema does not touch `SelfModel` on disk, the identity prompt slab, or any loop behavior, so it is safe even while 113 Phase E is pending. If 113 were reverted, the page would simply not surface those fields — a strictly narrower exposure, never a broken one.
- **Trust chain.** Untouched. `public_identity` stays a GET-only, rate-limited, curated projection behind the 038 `PublicApiMiddleware`; the field set only *shrinks*. No approval, sandbox, tool-gating, or auth surface changes; the `/account` operator dashboard is not modified.
- **Falsifiability.** If the design is right, the count of public-surface facts that diverge from the architecture is held at zero by CI: the framing-binding and phase-coverage tests pass on the live tree and would fail on a reintroduced stale phrase or a new uncovered loop phase, and the orb reports the real phase while `lifecycle.json` shows `tend_evolution_prs` / `run_task`. The design has **failed** if a later architecture change (a new loop phase, a further mission reframe) can land green without touching the page — i.e. if the binding tests do not break — which would mean the binding is cosmetic rather than load-bearing.
- **Rollback.** Phase A is additive (constants + tests) and reverts cleanly. Phases B–C are template/JS/CSS/schema edits behind no runtime state; a plain revert restores the prior page with no data migration, because nothing persisted changes.
