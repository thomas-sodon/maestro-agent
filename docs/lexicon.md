# Coined-Term Lexicon

Maestro thinks in coined hyphenated compounds — fusing a recurring behaviour into a
single handle is how the agent builds concepts. This file is the checked-in definitional
source of truth for those coinages: one row per term, mapping its canonical spelling to
the behaviour it names, its code anchor, the spellings it collapses, and the moment it
was minted. Read it with `maestro lexicon`; parse it with `maestro/lexicon.py`.

This seed is **deliberately non-exhaustive** — it covers the most load-bearing coinages
plus a couple of contemplation sensor tags, and only needs to be well-formed. Exhaustive
coverage, a coverage golden test, and lint/undefined-coinage tooling are follow-on work.

Columns: `term` (canonical spelling) · `definition` (one line) · `names` (the
behaviour/concept it points at) · `anchor` (code symbol, config flag, sensor, or
`prose-only`) · `variants` (comma-separated spellings it collapses; empty allowed) ·
`minted` (the proposal, journal moment, or audit event that crystallised it).
